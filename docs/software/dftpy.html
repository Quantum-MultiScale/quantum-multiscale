DFTpy

Python-based orbital-free DFT code for large-scale materials simulations. Million-atom systems are approachable via highly efficient parallelization and algorithms (e.g., PME and novel OF-DFT solvers).

GitHub Repo

dftpy.rutgers.edu

Quickstart

Install
Minimal run
import dftpy as dp

# toy example: set up a simple calculation
calc = dp.Calculation(
    lattice="fcc",
    element="Al",
    lattice_constant=4.05,
    kpoints=[4,4,4],
)
result = calc.run()
print("Total energy (eV):", result.total_energy)

Key Capabilities

Scalability

Strong/weak scaling on large systems via domain decomposition and efficient solvers.

Algorithms

PME, optimized kernels, and OF-DFT functionals for speed without sacrificing accuracy.

Pythonic API

Clean configuration objects, easy scripting, and compatibility with typical PyData tools.
