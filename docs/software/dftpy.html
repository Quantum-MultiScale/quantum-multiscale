DFTpy

DFTpy is a Python based code to run orbital-free DFT simulations. Million-atom systems are approachable thanks to the highly efficient parallelization and algorithms (such as PME and novel OF-DFT solvers).

‘Source Code <https://gitlab.com/pavanello-research-group/dftpy> ‘
