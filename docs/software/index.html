Software

Q-MS teams develop software for first principles multiscale modeling based on continuum embedding and density embedding. The main code bases are :

Code

What it does

QMultiPy

QMultiPy is a unifying interface that brings existing quantum simulation engines such as DFTpy, QEpy, and eDFTpy—under one roof.

DFTpy

DFTpy is an orbital-free Density Functional Theory code based on a plane-wave expansion of the electron density entirely coded in Python.

eDFTpy

eDFTpy combines Kohn-Sham Density Functional Theory (KS-DFT) and orbital-free DFT (OF-DFT) in an embedding framework that distills the best of both worlds.

QEpy

QEpy turns Quantum ESPRESSO (QE) into a Python DFT engine for nonstandard workflows. QEpy allows the user to include external potentials, use custom xc functionals, and much much more.

QMLearn

Quantum Machine Learning by learning one-body reduced density matrices in the AO basis.

OFPP

This is a library of pseudopotentials (PPs) for Orbital-Free Density Functional Theory (OF-DFT)
