QEpy

Quantum ESPRESSO in Python

QEpy turns Quantum ESPRESSO (QE) into a Python DFT engine for nonstandard workflows.
QEpy allows the user to include external potentials, use custom xc functionals, and can be used as a calculator for ASE.
