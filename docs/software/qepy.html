Software / QEpy

QEpy

QEpy turns Quantum ESPRESSO (QE) into a Python DFT engine for nonstandard workflows. QEpy allows the user to include external potentials, use custom XC functionals, and can also be used as a calculator for ASE.

GitHub Repo qepy.rutgers.edu
