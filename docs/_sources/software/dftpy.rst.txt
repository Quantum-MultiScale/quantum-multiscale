Quickstart
----------

.. grid:: 12
   :gutter: 2
   :margin: 0 0 2 0

   .. grid-item-card:: Install
      :columns: 6
      :class-card: app-card

      .. tabs::

         .. tab:: pip
            .. code-block:: bash

               pip install dftpy

         .. tab:: conda
            .. code-block:: bash

               conda install -c conda-forge dftpy

   .. grid-item-card:: Minimal run
      :columns: 6
      :class-card: app-card

      .. code-block:: python

         import dftpy as dp

         # toy example: set up a simple calculation
         calc = dp.Calculation(
             lattice="fcc",
             element="Al",
             lattice_constant=4.05,
             kpoints=[4,4,4],
         )
         result = calc.run()
         print("Total energy (eV):", result.total_energy)


Key Capabilities
----------------

.. grid:: 12
   :gutter: 2
   :margin: 0 0 1 0

   .. grid-item-card:: Scalability
      :columns: 4
      :class-card: app-card

      Strong/weak scaling on large systems via domain decomposition and efficient solvers.

   .. grid-item-card:: Algorithms
      :columns: 4
      :class-card: app-card

      PME, optimized kernels, and OF-DFT functionals for speed without sacrificing accuracy.

   .. grid-item-card:: Pythonic API
      :columns: 4
      :class-card: app-card

      Clean configuration objects, easy scripting, and compatibility with typical PyData tools.
